Bu yazılım uygulaması, kullanıcı tarafından girilen dikdörtgenin kenar uzunluklarını kullanarak, bu geometrik şeklin alanını ve çevresini hesaplama yeteneğine sahiptir. Söz konusu proje, öğrenim hayatımın erken dönemlerinde gerçekleştirdiğim temel programlama çalışmalarından birini temsil etmektedir.



This software application provides the functionality to calculate the area and perimeter of a rectangle based on the user-inputted side lengths. This project represents a fundamental programming work from my early academic years.
